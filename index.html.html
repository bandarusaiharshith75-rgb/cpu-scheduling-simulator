Operation log

Each scheduling decision will be explained here in plain English.

Aim

To write a C program that simulates the CPU scheduling algorithms First-Come First-Served (FCFS), Shortest Job First (SJF, non-preemptive), Shortest Remaining Time First (SRTF, preemptive SJF), Round Robin (RR) and Multi-Level Feedback Queue (MLFQ); draw the Gantt chart; and compute the completion time, turnaround time and waiting time of every process together with the average turnaround and waiting time.

Apparatus / software

PC with any OS, a C compiler (GCC / Turbo C / Code::Blocks), and a web browser for this simulator.

Theory

The CPU scheduler (short-term scheduler) selects one process from the ready queue and gives it the CPU. A non-preemptive scheduler lets the process run until it finishes; a preemptive scheduler can take the CPU away (when a time quantum expires or a better process arrives).

Key terms

  • Arrival Time (AT) — the time the process enters the ready queue.
  • Burst Time (BT) — the total CPU time the process needs.
  • Completion Time (CT) — the time the process finishes execution.
  • Turnaround Time (TAT) — total time spent in the system.
  • Waiting Time (WT) — time spent waiting in the ready queue.
  • Response Time (RT) — time from arrival until the process first gets the CPU.
TAT = CT − AT
WT  = TAT − BT
RT  = (first time on CPU) − AT
Average TAT = ΣTAT / n    Average WT = ΣWT / n
Throughput = n / (total schedule length)    CPU utilisation = busy time / total time × 100%

Algorithms

AlgorithmSelection rulePreemptive?Strength / weakness
FCFSProcess that arrived first.NoSimple and fair in order; suffers the convoy effect when a long job comes first.
SJFReady process with the smallest burst time.NoOptimal average WT among non-preemptive schedules; long jobs may starve; burst time must be known.
SRTFReady process with the smallest remaining time; re-checked every time unit.YesOptimal average WT overall; many context switches; starvation possible.
RRHead of a FIFO queue, for at most one time quantum, then back to the tail.YesGood response time, no starvation; performance depends on the quantum size.
MLFQHighest non-empty queue. Here: Q0 = RR (q0), Q1 = RR (q1), Q2 = FCFS. A process using its whole quantum is demoted one level; a waiting process in a higher queue preempts a lower one.YesFavours short and interactive jobs without knowing burst times; more complex; can starve Q2 (solved with aging / priority boost).

Procedure

  1. Read the number of processes n, and the arrival time and burst time of each process (and the time quantum for RR / MLFQ).
  2. Set the clock time = 0 and copy each burst time into a remaining time array.
  3. At each scheduling point, add newly arrived processes to the ready queue and choose the next process by the algorithm's rule. If no process is ready, the CPU is idle: advance the clock.
  4. Run the chosen process (fully, for one time unit, or for one quantum) and advance the clock. Record the Gantt chart slot.
  5. When a process's remaining time reaches 0, record CT = time, then compute TAT = CT − AT and WT = TAT − BT.
  6. Repeat until every process has finished, then print the table and the averages.
  7. Verify the result with this simulator: enter the same input, select the algorithm, and compare the Gantt chart and table.

Result

The CPU scheduling algorithms FCFS, SJF, SRTF, RR and MLFQ were simulated. The Gantt charts, completion, turnaround and waiting times were obtained and checked against the C program output.
